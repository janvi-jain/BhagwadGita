# 🕉️ Bhagavad Gita Web App

A responsive and user-friendly web application based on the **Bhagavad Gita**, designed to help users explore its chapters, verses, teachings, and spiritual wisdom through a clean and simple interface.

## ✨ Features

* 📖 Explore Bhagavad Gita chapters
* 🕉️ View verses and their teachings
* 🔍 Easy and simple navigation
* 📱 Fully responsive design
* 🎨 Clean and modern user interface
* 📚 Organized chapter-wise content
* 💻 Beginner-friendly frontend project

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Bootstrap
* Responsive Design
* Media Queries

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/janvi-jain/BhagwadGita
```

### 2. Open the project

Open the project folder in **VS Code**.

### 3. Run the project

You can open `index.html` directly in your browser or use **Live Server** in VS Code.

## 🎯 Purpose of the Project

The main purpose of this project is to create a simple digital platform where users can explore the teachings of the **Bhagavad Gita** in an organized and accessible way.

This project also helped me practice:

* Responsive web design
* Bootstrap components
* CSS styling
* JavaScript functionality
* Website layout and navigation
* Media queries
